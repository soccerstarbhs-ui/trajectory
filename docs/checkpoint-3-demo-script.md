# Trajectory — Checkpoint 3 Demo Script

Target: **1:35 presentation + 0:25 question buffer**

## 0:00–0:15 — Open on the decision

**Screen:** Complete onboarding with the research-deficient profile, then point to “Highest Impact This Week.”

“College planning tools usually begin with courses. Trajectory begins with the destination, maps the dependencies and opportunities between the student and that goal, and identifies the highest-value action they can take this week.”

## 0:15–0:35 — Explain the score

**Action:** Open the recommendation.

“This student’s largest gap is sustained research, so Trajectory recommends a qualified lab opportunity. Action Impact is a transparent relative score combining gap reduction, downstream value, evidence strength, mission fit, feasibility, and timing, minus uncertainty. It is not an acceptance probability.”

## 0:35–0:50 — Reveal the evidence

**Action:** Open “Review supporting evidence.”

“Every important recommendation exposes its source, evidence type, population, confidence, causal label, limitations, and last-reviewed date. Empirical evidence is separated from model inference, so the student can see what is known and what remains uncertain.”

## 0:50–1:12 — Trigger rerouting

**Action:** Return to the graph and select “Simulate research rejection.”

“A rejection is not a dead end. The blocked lab leaves the eligible set, and Trajectory immediately surfaces the alternative that preserves the most downstream value.”

**Action:** Select “Announce Columbia fellowship.”

“When a qualified, deadline-sensitive opportunity appears, the route changes again. The same engine responds to both setbacks and new information.”

## 1:12–1:28 — Show the what-if

**Action:** Select “Skip Organic Chemistry I.”

“Students can also test decisions before making them. Skipping Organic Chemistry blocks three downstream courses, pauses the sequence, and makes Organic Chemistry I the recovery priority.”

## 1:28–1:35 — Close

**Screen:** Return to the graph overview.

“Trajectory does not merely list requirements or estimate competitiveness. It continuously recalculates the next-best move: GPS for your future, not a course planner.”
